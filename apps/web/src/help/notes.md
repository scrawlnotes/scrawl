# 📝 Notes

A note is for writing: meeting notes, plans, drafts, anything. Each note is a Markdown file in its folder, so it opens in any other editor too.

## Make a note

Press **+** beside the tabs and pick **Note**. Give it a name and a folder, or leave the name empty: the note is then called by its first line. **+** on a folder in the sidebar makes it right there.

## Writing

What you type stays as you typed it: a `*` or a `#` stays a character and does not turn into formatting. Formatting comes from the bar above the note: bold, italic, strikethrough, code, link, headings, lists, quote, callout and code block.

Two shortcuts of other note apps work here too:

- Start a line with `- `, `* ` or `1. ` and it becomes a list. **Undo** right after turns it back into text.
- Type `/` at the start of a line, or after a space, for what you can add: a heading, a list, a quote, a callout, a code block, a table, a divider or an image.

The note shows formatted, without its Markdown marks. **Markdown** in the status bar shows the file as it is written.

**Find** in the bar finds and replaces words in the note.

## Tables

A table is a grid you write in: click a cell and type, and move between cells with **Tab** and **Enter**. Rows and columns are added and taken off in the table itself.

Cells copied from Excel, Google Sheets or Numbers, or a table copied from a web page, come in as a table, its first row as the header.

## Images, files and recordings

Paste an image, or drop any file on the note. A file that is not an image shows as a link and opens in its own program. The bar also records your voice.

Click an image, a file or a recording to open, rename or delete it. Every file added to a note, a card or a record is listed in **Files**, at the foot of the sidebar.

## Callouts

A callout is a colored box for a note, a tip, something important, a warning or a caution. Pick **Callout** in the bar or after `/`. Click its title to change its kind, or to take the box off and keep its lines.

## Turning text into work

Select a line or more and press **To task** or **To card** in the bar. The first line becomes the title, the rest its description. The task or the card links back to the note; the note stays as it was. See [Task lists](task-lists) and [Boards](boards).

## History

Scrawl keeps earlier versions of each note on this device: at most one every 10 minutes, all of the last day, then one a day for 60 days. Right-click the note and choose **History…** to look at one and **Restore** it; what the note says now is kept as a version too.

When an agent rewrites a note, the earlier version is there as well.

## Export

**Export…** in the note's menu saves it as a PDF, as a single HTML file with its images in it, or as Markdown with its files in a zip.

## Copying

What you copy from a note goes as plain text, as formatted text for Word or an email, and as Markdown for another note; each place takes the one it understands. Text pasted from elsewhere comes in plain, except cells from a spreadsheet.
